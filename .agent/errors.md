# Ошибки агента и способы их исправления

## 1. Неверный разбор суммы в немецкой локали

- **Когда:** запрос 1, при первом прогоне тестов
- **Что случилось:** `ConverterViewModel` разбирал `1.234,5` (de_DE) как `1.234` вместо `1234.5`.
  Разделитель групп `.` пропускался особым условием, а потом `,` заменялась на `.`,
  и строка превращалась в `1.234.5`.
- **Как нашли:** параметризованный тест `parsesAmountInLocale` упал на кейсе de_DE.
- **Исправление:** разбор вынесен в отдельный `AmountParser` с явными правилами: если в строке
  есть и `.`, и `,`, десятичный разделитель — тот, что встречается последним; одиночный разделитель
  считается групповым, только если он совпадает с разделителем групп локали и делит число на группы
  по 3 цифры. Добавлено 25 тест-кейсов (`tests/ios/AmountParserTests.swift`).

## 2. `xcodebuild test` зависал после завершения тестов

- **Когда:** запрос 1
- **Что случилось:** тесты отработали примерно за 20 секунд, но процесс `xcodebuild` не завершался
  10+ минут, и команду пришлось остановить.
- **Как нашли:** агент прочитал лог сессии из `.xcresult` и увидел, что тесты закончились.
- **Исправление (обход):** запуск с `-enableCodeCoverage NO -parallel-testing-enabled NO` и
  слежение за логом с остановкой процесса после строки `Test run with …`. После этого
  `xcodebuild` завершался штатно (`** TEST SUCCEEDED **`). Первопричина не выяснена.

## 3. Команда `timeout` отсутствует в macOS

- **Когда:** запрос 1
- **Что случилось:** агент обернул тесты в `timeout 300 …`, а в macOS нет GNU coreutils — exit code 127.
- **Исправление:** ограничение по времени сделано циклом в shell с `kill` фонового процесса.

## 4. Тестовый таргет SwiftPM вне корня пакета

- **Когда:** запрос 2, проверка гипотезы до написания кода
- **Что случилось:** при `Package.swift` внутри `src/server` тесты в `tests/server` дают ошибку
  `target 'T' in package 'server' is outside the package root`.
- **Исправление:** решено держать `Package.swift` в корне репозитория. Ошибка поймана
  на одноразовом тестовом пакете, а не в проекте.
