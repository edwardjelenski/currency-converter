# Ошибки агента и способы их исправления

Всё, что пошло не так по вине агента: сборка не прошла, упал тест, сработала не та команда,
агент неверно понял задачу. Записи в хронологическом порядке, номер запроса — по
[prompt-log.md](prompt-log.md). Запись добавляет сам агент, как только сбой случился
(правило в [CLAUDE.md](../CLAUDE.md)).

---

## 1. Проверка результата сборки ничего не показала

- **Когда:** запрос 1, первая сборка слоя данных
- **Что было:** команда сборки заканчивалась на `echo "exit ${PIPESTATUS[0]}"` и вывела пустое `exit`:
  по выводу нельзя было понять, собралось ли.
- **Причина:** `PIPESTATUS` — переменная bash, а оболочка пользователя — zsh (там она называется `pipestatus`).
- **Как исправил:** перезапустил сборку и смотрел на строку `** BUILD SUCCEEDED **` / `error:`
  в выводе `xcodebuild`, а не на код возврата пайпа.

## 2. Неверный разбор суммы в немецкой локали — упал тест

- **Когда:** запрос 1, первый прогон тестов
- **Что было:** параметризованный тест `parsesAmountInLocale` упал на кейсе `de_DE`, `"1.234,5"`:
  ожидалось `1234.5`, получилось `1.234`.
- **Причина:** в `ConverterViewModel` разделитель групп `.` нарочно не удалялся (чтобы `0.25` в русской
  локали работал как дробь), а затем `,` заменялась на `.` — строка становилась `1.234.5`,
  и `Decimal(string:)` разбирал только начало.
- **Как исправил:** вынес разбор в отдельный `AmountParser` с явными правилами: если в строке есть
  и `.`, и `,`, десятичный разделитель — тот, что встречается последним; одиночный разделитель считается
  групповым, только если он совпадает с разделителем групп локали и делит число на группы по 3 цифры.
  Добавил 25 тест-кейсов (`tests/ios/AmountParserTests.swift`).

## 3. `xcodebuild test` не завершался после тестов

- **Когда:** запрос 1
- **Что было:** команда тестов висела больше 10 минут и была снята по таймауту инструмента.
- **Причина:** не установлена. По логу сессии в `.xcresult` тесты закончились примерно за 20 секунд,
  а сам `xcodebuild` после этого не выходил. Подозрение на сбор покрытия кода или параллельный запуск тестов.
- **Как исправил (обход):** перезапуск с `-enableCodeCoverage NO -parallel-testing-enabled NO` и
  фоновым процессом, который снимается после строки `Test run with …` в логе. С этими флагами
  `xcodebuild` завершается штатно (`** TEST SUCCEEDED **`).

## 4. Команда `timeout` не найдена

- **Когда:** запрос 1, повторный прогон тестов
- **Что было:** `timeout 300 xcodebuild test …` завершился с кодом 127, тесты не запустились.
- **Причина:** `timeout` — утилита GNU coreutils, в macOS её нет.
- **Как исправил:** ограничение по времени сделал циклом в shell: фоновый процесс + проверка
  лога каждые 5 секунд + `kill`.

## 5. Лишняя попытка выключить симулятор

- **Когда:** запросы 1 и 2, после тестов
- **Что было:** `xcrun simctl shutdown <udid>` вернул ошибку `Unable to shutdown device in current state: Shutdown`.
- **Причина:** агент не проверил состояние: симулятор к этому моменту уже был выключен (его гасит `xcodebuild`).
- **Как исправил:** на работу не повлияло. Правильнее сначала смотреть `xcrun simctl list devices | grep Booted`.

## 6. Проверка на захардкоженные стили не выполнилась

- **Когда:** запрос 2, вынос стилей в `styles/Theme.swift`
- **Что было:** команда `grep -rn … --include=*.swift .` упала с `no matches found: --include=*.swift`,
  проверка не прошла.
- **Причина:** zsh раскрывает `*` в аргументе как glob и падает, если совпадений нет. В bash такой
  аргумент передался бы в grep как есть.
- **Как исправил:** перезапустил grep без glob-аргумента (поиск только по папке исходников);
  захардкоженных цветов и радиусов вне `styles/` не осталось.
