## 1. Создание iOS-проекта

**Промпт:**

> создай новый ios проект - конвертер валют. swiftui, ios 17+, swift 6 со strict concurrency. проект генерь через xcodegen (project.yml в репе, .xcodeproj в gitignore), bundle id com.eduardyelenskiy.currencyconverter
>
> создай публичную репу через gh cli (я залогинен), добавь какой нибудь самый популярный .gitignore под ios проект. дальше по ходу работы коммить в main осмысленными коммитами и пушь

**Результат:**
- Публичный репозиторий, `.gitignore` из официального шаблона GitHub `Swift.gitignore` + `*.xcodeproj`
- XcodeGen-проект: Swift 6, `SWIFT_STRICT_CONCURRENCY = complete`, iOS 17
- Слой данных (Frankfurter API, кэш на диске через `actor`), экран конвертера, выбор валюты с поиском
- 21 unit-тест на Swift Testing; внешний вид проверен рендером `#Preview` через Xcode MCP
- 6 осмысленных коммитов, каждый запушен в `main`

**Что сработало:** короткий, но конкретный промпт (версии, инструменты, bundle id, правила по git)
дал предсказуемый результат без уточняющих вопросов.

**Что пришлось исправлять:** агент сам нашёл ошибку разбора суммы `1.234,5` в немецкой локали
благодаря тестам и переписал парсер (см. [.agent/errors.md](.agent/errors.md)).
